# DSA in Java 🚀

Welcome to my **Data Structures and Algorithms (DSA) in Java** repository! This repository contains my solutions and practice problems as I strengthen my problem-solving skills and prepare for software engineering interviews.

## 📚 Topics Covered

### 1. Graph Algorithms

Located in the `Graph/` folder.

* **Graph Basics:** Graph representation and adjacency lists
* **BFS:** Breadth-First Search, connected components, grid problems
* **DFS:** Depth-First Search, flood fill, distinct islands
* **Cycle Detection:** Directed and undirected graphs using BFS and DFS
* **Topological Sorting:** Kahn's Algorithm, DFS-based sorting, Course Schedule, Alien Dictionary
* **Shortest Paths:** Dijkstra's Algorithm, Bellman-Ford, Floyd–Warshall, DAG shortest paths
* **Graph Interview Problems:** Clone Graph, Minimum Height Trees, Pacific Atlantic Water Flow, and more

### 2. Binary Search

Located in the `BinarySearchProblems/` folder.

* Binary Search on Arrays
* First and Last Occurrences
* Lower Bound and Upper Bound
* Binary Search on Answers
* Search in Rotated Sorted Arrays
* Binary Search on 2D Arrays

*The topics listed reflect the intended coverage; solutions will be added and updated as I progress.*
